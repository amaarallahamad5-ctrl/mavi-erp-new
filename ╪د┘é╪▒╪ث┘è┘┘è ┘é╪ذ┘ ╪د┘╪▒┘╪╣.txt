تحديث موقع MAVI ولوحة الإدارة — عربي / English

هذه الحزمة تحتوي الملفات المعدلة فقط، وليست نسخة كاملة من المشروع. مبنية على آخر نسخة GitHub main التي تم فحصها عند تجهيزها: e5efc4e49e713b4d8e30071ee9c63f445358f425.

قبل الرفع: احتفظي بنسخة احتياطية آمنة من قاعدة بيانات Suga والملفات المرفوعة. لا تحذفي المشروع الحالي ولا الـVolume. لو تم تحديث نفس ملفات public على GitHub بعد هذا الإصدار، توقفي عن استبدالها حتى تتم مقارنة التعديلات.

خطوات الرفع:
1. فكّي ضغط الملف على جهازك. لا ترفعي ملف ZIP نفسه كما هو.
2. افتحي مستودع GitHub الحالي، وفرع main. ارفعي ملفات مجلد public المرفق إلى مجلد public الموجود بالمستودع مع الحفاظ تمامًا على المسارات والأسماء، ووافقي على استبدال الملفات المطابقة فقط. يمكن الرفع على دفعات من داخل public، ثم admin وstore في مجلداتهما. ارفعي mavi-i18n.js داخل public مباشرة.
3. اعملي Commit للتعديلات. عند وجود نشر تلقائي متصل بالفرع انتظري انتهاء البناء؛ وإلا اختاري إعادة النشر من Suga. هذا الملف لا ينشر التحديث وحده.
4. لا تغيّري إعدادات التخزين أو متغيرات Suga الحالية: DB_PATH=/data/mavi-restored.db وAUTO_SEED=0 وSHOW_OTP=0؛ لا تشغّلي seed أو reset أو restore ولا تحذفي /data. راجعي إعداداتك الحالية قبل النشر.
5. بعد النشر افتحي /store/ و/admin/ وحدّثي الصفحة، واختبري زر اللغة وتسجيل الدخول والطلبات بدون إنشاء بيانات اختبار حقيقية. تطبيق الإدارة WebView يعرض الموقع بعد تحديثه.

البيانات المكتوبة من المستخدمين وبعض رسائل الخادم غير المعروفة قد تبقى بالعربية. إذا انقطع الاتصال أثناء إرسال طلب فقد تكون العملية قد نجحت: افحصي الطلبات قبل إعادة الإرسال. تعطيل الزر أثناء الإرسال ليس ضمانًا لمنع كل الطلبات المكررة.

التطبيق الأصلي الذي تمت مراجعته هو إصدار تجريبي منفصل وليس تحديث Android إنتاجي. هذه الحزمة لا تحتوي APK ولا تغيره. لا توجد بيانات عميلات أو قاعدة بيانات أو مفاتيح توقيع في هذه الحزمة.
