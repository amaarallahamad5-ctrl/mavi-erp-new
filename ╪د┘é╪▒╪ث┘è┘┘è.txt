تحديث تجريبي آمن لفحص الصحة — MAVI

هذا ليس ضماناً لإصلاح انقطاع Deplexo. ينقل فحص /healthz قبل قراءة بيانات الجلسات مع استمرار اختبار قاعدة البيانات، ويختبر الاستجابة من داخل الخادم كل 30 ثانية دون تسجيل بيانات العملاء. لا يغيّر قاعدة البيانات أو إعدادات الاستضافة.

قبل النشر احفظي نسخة احتياطية من بيانات الإنتاج إن أمكن. لا تحذفي التطبيق ولا قاعدة البيانات أو مجلد /data. لا تضعي كلمة مرور أو قاعدة البيانات على GitHub. أثناء إعادة النشر قد ينقطع الموقع مؤقتاً.

فكي ضغط الملف. في مستودع GitHub الحالي افتحي مجلد src، واختاري Add file ثم Upload files. اسحبي الملفين server.js وhealth-monitor.js من مجلد src داخل الملف المضغوط إلى مجلد src المفتوح على GitHub (وليس إلى الصفحة الرئيسية للمستودع). اضغطي Commit changes. اختاري استبدال server.js إذا ظهر السؤال. لا تحذفي بقية ملفات المشروع. يُفترض نشر التعديل بالطريقة المعتادة على Deplexo.

مهم: ملف server.js مبني على نسخة المستودع التي كانت أحدثها 912bc118؛ إذا عدلتِ server.js منذ ذلك الوقت فلا تستبدليه قبل مراجعة الاختلافات حتى لا تفقدي تعديلاتك.

عندما يرجع الموقع 503 افتحي Runtime Logs وابحثي عن mavi-local-health، وأرسلي السطور القريبة من وقت الانقطاع ووقت حدوثه. http_status 200 يعني أن الفحص المحلي نجح في تلك اللحظة؛ 0 يعني فشل الاتصال أو انتهاء المهلة. نجاح الفحص الداخلي مع فشل الرابط الخارجي يقوّي احتمال مشكلة في المسار أو التوجيه، ولا يثبت سببها. لا ترسلي أي أسرار.
