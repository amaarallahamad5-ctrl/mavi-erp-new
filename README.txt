MAVI Smart Alerts + Unified Cart — STAGING OVERLAY ONLY

This partial source overlay supersedes the earlier cart and notification staging packages. It is based on f6c79a3 and local cart/alert work. It is not a complete application and has not been deployed to production. Compare all included files with the actual live source and merge any newer changes rather than overwriting them blindly.

Before any deployment back up and verify the production database AND uploads. Test first on an isolated staging copy, protect personal data, preserve environment variables, secrets, uploads and existing VAPID keys. Do not seed, reset, or restore test data over production. Migrations are additive and retain old alert history; alert triggers are recreated. Do not assume rollback can reverse database changes: prepare and test a rollback plan.

Includes mixed cart, floating cart and notification bell, readable alert cards with current order status, direct customer/admin details, legacy custom design details and authorized photos, and receipt upload. Old alerts may not have enough reference data to open a specific order. Admin permissions remain role dependent. Push carries generic text and an opaque event ID; the server checks the logged-in user's authorization before opening an alert target. Browser/device support, permission and per-device opt-in are required; delivery is not guaranteed. It does not add native Android push.

Local checks: 57/57 core tests; cart, notifications, migration, private customer isolation, service-worker simulated push and click; browser tests for customer/admin links, quote, old custom design/photo, receipt, target URL and responsive widths 320–1280. No real push delivery on a physical phone and no production or staging deployment have been verified. On staging test real devices and customer/admin permission, old orders, images, receipt, pricing, mixed cart, account switching and old notification links before considering deployment. Price changes between cart addition and checkout and ambiguous network failures need particular attention.
